# README

## Язык программирования:
C++

## Описание:
Это программное обеспечение предназначено для управления пользователями и группами в операционных системах Windows. Оно предоставляет удобный интерфейс для работы с пользователями и группами, а также позволяет управлять их привилегиями.

### Работа с группами:
- **Получение информации о группе/группах:**  
  Просмотр всех групп в системе или получение информации о конкретной группе.
  
- **Создание/Удаление группы:**  
  Возможность создания новой группы с заданным именем и описанием, а также удаление существующих групп.

- **Добавление/Удаление привилегий:**  
  Группам можно назначать или удалять различные привилегии, чтобы контролировать их доступ к ресурсам системы.

- **Изменение названия/описания группы:**  
  Обновление имени или описания существующих групп для удобства управления.

### Работа с пользователями:
- **Получение информации о пользователе/пользователях:**  
  Возможность получить информацию о всех пользователях системы или конкретном пользователе по имени.

- **Создание/Удаление пользователя:**  
  Создание новых пользователей с заданным именем и паролем, а также удаление существующих пользователей.

- **Добавление/Удаление привилегий:**  
  Пользователи могут получить или потерять определенные привилегии, такие как права администратора, доступ к системе и другие.

- **Добавление/Удаление пользователей в/из группы:**  
  Возможность добавить пользователей в группы или удалить их, что позволяет эффективно управлять правами доступа.

## Требования:
- Операционная система: Windows
- Компилятор C++ (например, Microsoft Visual Studio)
